What it isWhy we use itHow it works
What

A routing pool puts several hosts’ Cal.com calendars behind one link. Bookers see everyone’s free time as one.

Why

3

Invites are automatic

How
  1. 1

    Hosts connect Cal.com

    Paste a Cal.com API key, then Verify.

  2. 2

    Admin creates a pool

    Name, public link, and “Round robin”.

  3. 3

    Add hosts to the pool

    Pick each host and their event type.

  4. 4

    Share the link

    Motherboard picks a free host for every booking.
